# Food Delivery Full Stack App

A full-stack food delivery web application built using React, Node.js, Express, and MongoDB.

## Features

- User registration and login
- Browse food items
- Add items to cart
- Place orders
- Online payment integration using Stripe
- Admin panel to add, list, and manage food items
- Order management system

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Stripe Payment Gateway

### Admin Panel
- React
- Vite
- Axios
